# 南溪江TV · GitHub Pages 测试版

无需 Node.js 构建、服务器或 PASSWORD 环境变量的独立静态播放器。版本 1.0.4。

## 1.0.4 更新：网络热榜与片源库

原“首页热榜”更名为“网络热榜”。导航新增独立“片源库”：

- 下拉选择在设置中启用的片源；新增片源后启用，即可在片源库选择。
- 读取该片源提供的大分类、细分类，点击分类请求对应的服务端影片列表，不是本页筛选。
- 支持上一页/下一页、首页/末页、页码选择和输入页码跳转。切换片源时，各片源在本次打开期间分别保留分类和页码。
- 点击影片直接打开已有播放器和选集，复用历史续播、倍速、横屏全屏。
- 不提供分类的接口只显示全部列表并提示；连接失败可刷新或切换片源。

本地验证不代表所有自定义源均兼容；分类、更新和可播放情况取决于片源返回。更新仍将完整文件覆盖上传到原仓库，底部版本应为 1.0.4。

## 1.0.3 更新：手机横屏全屏

视频下方新增两个明确入口：

- **横屏全屏**：使用网页播放器。手机竖屏且影片为横向画面时，视频和控制区一起旋转 90°，按原比例显示；转动设备后重新计算尺寸。不会裁切或拉伸画面。
- **系统全屏**：使用设备原生播放器。iPhone 若保持竖屏，可先在控制中心关闭竖排方向锁定，再横拿手机。

网页横屏内提供播放/暂停、拖动进度、倍速、上一集/下一集、系统全屏和退出。播放时控制区约 3.5 秒后自动隐藏，点击画面重新显示；暂停时保持显示。支持 Escape 退出和键盘操作。

网页横屏无法保证隐藏 Safari 地址栏和系统状态栏；通过 Safari“添加到主屏幕”后打开，可减少浏览器界面的占用。不同宽高比的视频仍可能有必要的黑边。已在竖屏浏览器中测试，未完成 iPhone 真机验证。

本版已包含 1.0.2 的更新缓存修复。覆盖上传完整文件，部署完成后刷新；页面底部版本应为 **1.0.3**。原有观看记录和片源配置不需要删除。

## 1.0.2 更新：避免新旧页面资源混用

页面入口、样式、播放器和所有本地 JS 模块使用统一的 `?v=1.0.2` 资源地址。Service Worker 安装时重新获取资源，联网访问时重新校验，离线回退仅使用当前版本缓存。

如果看到 `Cannot set properties of null (setting 'hidden')`，并且热榜分类未出现，很可能浏览器仍加载着旧版脚本。将本版本所有文件覆盖上传到原仓库，等待 GitHub Pages 部署完成，再按 **Ctrl + Shift + R** 强制刷新。页面底部应显示 **1.0.2**。

也可以先用无痕窗口检查网站是否恢复。无需删除网站数据；清除网站数据会丢失本机片源配置和观看记录。

## 1.0.1 更新

首页增加电影周榜、国产剧周榜、海外剧周榜、国内综艺、海外综艺、百度热播剧六类热榜。点击海报会搜索已启用的片源，榜单不等同于可播放影片库。
每个分类按需读取，成功结果在本机缓存 30 分钟，可点击“刷新热榜”强制更新。接口失败时明确提示错误；有旧缓存时标明上次获取时间。
榜单由 [60s API](https://github.com/vikiboss/60s) 聚合提供，公共接口有额度与网络限制。此功能不要求服务器或密钥，不影响手动搜索。

已有 Pages 1.0.0 用户：将新版文件覆盖上传到原仓库根目录即可，不需要新建仓库或更改 Pages 设置。等待 GitHub 部署完成后重新打开网址；如出现更新按钮，点击“更新并重新载入”。

## 上传和发布

1. 在 GitHub 新建一个 **Public（公开）** 仓库，建议名称 `nanxijiang-tv-pages`。保留原来 `nanxijiang-tv` 私有仓库。
2. 解压上传包，进入里面的文件夹。点击 GitHub 的 **uploading an existing file**（已有文件时为 **Add file → Upload files**），把文件夹里面的全部文件和子文件夹拖进去，提交。
3. 仓库首页应直接看见 `index.html`、`app.js`、`style.css`、`vendor`、`icons`，不能再套一层文件夹。`.nojekyll` 一并上传；本项目不依赖它才能运行。
4. 打开仓库 **Settings → Pages**。Source 选择 **Deploy from a branch**；Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
5. 等待 Pages 发布完成。GitHub 会在这个页面显示访问网址，通常需要数分钟。

若使用账号 `jiaxiaonan21-beep` 和上面的仓库名，预期网址为：
`https://jiaxiaonan21-beep.github.io/nanxijiang-tv-pages/`
这是预计地址，本地打包不会自动创建或发布该站点。

GitHub Free 的 Pages 使用公开仓库。代码和内置片源地址会公开；不要上传密码、令牌、私人片源配置或导出的播放记录。浏览器内的记录不会随源码上传。

## 使用

- 在“设置”检查、启用或添加片源，再到首页搜索。支持返回 `list` 数组的 CMS JSON 接口，以及 `vod_play_url` 中的 HTTPS 播放地址。
- 多个片源同时搜索，谁先返回就先显示；超时 8 秒。各源的集数、分页数据由片源提供。
- 支持选集、上一集/下一集、倍速、全屏、直链视频、浏览器支持格式的本地视频。
- 网络视频的集数和观看进度保存在本机，历史里可以继续播放、删除选中或删除未选中。
- “导出本机备份”保存片源和记录；“导入 JSON”可以导入本版本备份，或下面的片源配置。

```json
{"sources":[{"name":"我的片源","url":"https://example.com/api.php/provide/vod/","enabled":true}]}
```

本地视频每次需要重新选择，不保存本地文件权限或位置。本版不删除原文件、不下载影片、不含服务器代理、账号登录或云端同步。直播订阅和嵌入网站功能未迁入此精简版。

## iPhone / iPad

用 Safari 打开已发布网址，点击“分享 → 添加到主屏幕”。推荐更新系统和 Safari。
请使用视频下方的“横屏全屏”按钮打开网页横屏，或用“系统全屏”调用 iOS 播放器。视频原生控件中的全屏图标仍可能进入 iOS 系统播放器。

## 更新

将新版本文件上传覆盖到同一仓库，等待 Pages 发布。重新打开页面；出现“更新并重新载入”时点击更新。
主屏幕图标通常不需要重新安装。设备清理网站数据、无痕模式或更换网址可能导致本机记录消失，建议定期备份。

## 静态版本的限制

GitHub Pages 只提供 HTML、CSS 和 JavaScript，不运行原版的服务端接口。片源接口和视频都从设备直接访问。

- 片源接口必须允许浏览器跨域读取。返回搜索结果也不保证视频地址没有跨域、防盗链或编码限制。
- 只接受 HTTPS 片源和网络播放地址，避免 HTTPS 网页中的混合内容阻止。
- “无法读取片源”可能由跨域、DNS、证书或网络故障引起，浏览器不能总是给出确切原因。
- GitHub Pages 及第三方片源在国内的可访问性和速度无法保证。本版减少服务端中转，不保证比所有其他部署都快。
- 离线缓存仅保存网页和播放器代码，**不保存影片供离线观看**。
- 片源列表属于兼容性候选，并非稳定播放承诺。实际测试见 TEST_REPORT.md。
